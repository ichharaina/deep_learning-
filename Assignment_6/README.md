# Assignment 6 – CNN-Based Plant Disease Classification

## Problem Statement

Design and implement a Convolutional Neural Network (CNN) for image classification using the Tomato or Soybean disease dataset.

## Objective

To design and implement a CNN model for classifying plant images into different disease categories and understand how convolutional neural networks can be used for image classification.

## Dataset

A plant disease image dataset containing images of Tomato or Soybean plants is used for classification.

## Implementation

The implementation includes:

- Loading the plant disease image dataset
- Image preprocessing and resizing
- Normalization of image pixel values
- Splitting the dataset into training and validation/testing sets
- Designing a Convolutional Neural Network
- Applying convolution and pooling operations
- Training the CNN model
- Evaluating classification performance
- Visualizing training and validation performance

## CNN Architecture

The CNN consists of:

- Convolutional layers
- ReLU activation functions
- Max Pooling layers
- Flatten layer
- Fully Connected/Dense layers
- Softmax output layer

## Technologies Used

- Python
- TensorFlow
- Keras
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Evaluation Metrics

The model performance is evaluated using:

- Accuracy
- Loss
- Confusion Matrix
- Precision
- Recall
- F1-Score

## Result

The trained CNN classifies plant images into their respective disease categories. Training and validation accuracy and loss are analyzed to evaluate the model's performance.

## Conclusion

A CNN can automatically learn important visual features such as edges, textures, shapes, and patterns from plant images. These features can be used to classify different plant diseases and demonstrate the application of deep learning in agricultural image classification.
