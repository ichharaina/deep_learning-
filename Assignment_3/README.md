# Assignment 3: Neural Network Hyperparameter Analysis

## Aim

To study the effect of different **learning rates** and **number of epochs** on the performance of a neural network model and evaluate the model using classification accuracy.

---

## Objective

The main objectives of this assignment are:

- To implement a neural network classification model.
- To experiment with different learning rates.
- To study the effect of different numbers of epochs on model performance.
- To compare the resulting classification accuracies.
- To visualize and analyze the effect of these hyperparameters.

## Dataset

The assignment uses a dataset for classification and evaluates the trained neural network using accuracy.
